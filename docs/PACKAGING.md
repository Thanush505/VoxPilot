# VoxPilot — Production Packaging & Build Guide

This document describes how VoxPilot is packaged from source into a standalone, console-free Windows 11 desktop executable (`VoxPilot.exe`) and compiled into a per-user Windows Installer (`VoxPilot-Setup.exe`).

---

## 1. Version Authority

All packaging artifacts derive their canonical version from `VERSION` in the repository root (`0.5.4`):

| File | Purpose | Version Reference |
| --- | --- | --- |
| `VERSION` | Canonical plain-text semantic version | `0.5.4` |
| `backend/version.py` | Runtime semantic version parser and fallback | `DEFAULT_APP_VERSION = "0.5.4"` |
| `frontend/package.json` | React/Vite package manifest | `"version": "0.5.4"` |
| `assets/version_info.txt` | Windows PE `FileVersion` / `ProductVersion` metadata | `0.5.4.0` / `0.5.4` |
| `installer/VoxPilot.iss` | Reads `..\VERSION` at compile time via `#define MyAppVersion` | `VoxPilotTeam.VoxPilot.DesktopAgent.0.5.4` |

`VoxPilot.spec` enforces equality between `VERSION` and `backend.version.DEFAULT_APP_VERSION` at analysis time and aborts the build on mismatch.

## 2. Build Prerequisites (Windows 11)

1. **Python 3.12 Virtual Environment:** `.venv\Scripts\python.exe` with project dependencies and **PyInstaller** installed (`PyInstaller 6.22.3` verified).
2. **Node.js & npm:** Used to compile `frontend/dist` (`npm run build` inside `frontend/`).
3. **Inno Setup 6:** Installed at `%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe` (for compiling `installer/VoxPilot.iss`).
4. **Bundled Assets Present in Repo:**
   - `frontend/dist/` (generated by Vite)
   - `assets/icons/voxpilot.ico` and `assets/icons/voxpilot-icon-128x128.png`
   - `assets/version_info.txt`
   - `models/piper/en_US-lessac-medium.onnx` and `.onnx.json`
   - `README_DIST.txt` and `install_browser.bat`

## 3. Build Pipeline

### Step A — Build the Production Frontend

```powershell
cd C:\Users\Thanu\OneDrive\Desktop\VoxPilot\frontend
npm run build
```

This runs TypeScript type-checking (`tsc`) and outputs minified assets to `frontend/dist/`.

### Step B — Build the Console-Free Executable (`VoxPilot.spec`)

Ensure no running `VoxPilot.exe` process holds locks on `dist\VoxPilot\`, then run:

```powershell
cd C:\Users\Thanu\OneDrive\Desktop\VoxPilot
.\.venv\Scripts\python.exe -m PyInstaller VoxPilot.spec --noconfirm
```

Key `VoxPilot.spec` settings:
- **Entrypoint:** `launcher.py` (`console=False`, `WindowsGUI` subsystem, embedded icon & PE version info).
- **Dynamic Libraries & Data:** Collects `ctranslate2`, `onnxruntime`, `piper`, `openwakeword`, `faster_whisper`, Playwright driver, and **PyWebView / Edge WebView2 / Python.NET** (`webview`, `pythonnet`, `clr_loader`), including `Microsoft.Web.WebView2.Core.dll`, `WebView2Loader.dll`, `Python.Runtime.dll`, and `ClrLoader.dll`.
- **Hidden Imports:** Includes `backend.desktop`, `backend.desktop.shell`, `backend.database.backup`, `backend.ai.providers.*` (Ollama, OpenAI, Anthropic, Gemini), `backend.updater.*`, `webview`, `pythonnet`, `clr_loader`, `httpx`, and `cryptography`.
- **Excludes:** Strips dev/test-only modules (`tests`, `pytest`, `_pytest`, `vitest`, `tkinter`, `matplotlib`).

Output lands in `dist\VoxPilot\VoxPilot.exe` alongside `dist\VoxPilot\_internal\`.

### Step C — Compile the Inno Setup Installer (`installer/VoxPilot.iss`)

Always preserve or back up any previous release artifact in `installer\Output\` before overwriting.

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" "C:\Users\Thanu\OneDrive\Desktop\VoxPilot\installer\VoxPilot.iss"
```

After compilation, generate the release checksum manifest:

```powershell
$hash = (Get-FileHash "installer\Output\VoxPilot-Setup.exe" -Algorithm SHA256).Hash.ToLowerInvariant()
"$hash  VoxPilot-Setup.exe" | Set-Content -Path "installer\Output\SHA256SUMS.txt" -Encoding ASCII
```

## 4. Path Resolution & Runtime Safety Rules

- `backend/paths.py` separates **read-only bundle resources** (`get_bundle_dir()` / `sys._MEIPASS`) from **writable per-user data** (`get_user_data_dir()` -> `%LOCALAPPDATA%\VoxPilot`).
- Never store databases, credentials, logs, backups, downloads, or updates inside `dist\VoxPilot\` or `%LOCALAPPDATA%\Programs\VoxPilot`.
- Because `console=False` sets `sys.stdout` and `sys.stderr` to `None` under the Windows GUI bootloader, `ensure_safe_standard_streams()` (`backend/desktop/shell.py` and `launcher.py`) attaches safe UTF-8 stream fallbacks and file logging (`%LOCALAPPDATA%\VoxPilot\logs\voxpilot.log`).
